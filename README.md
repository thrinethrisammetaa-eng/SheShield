# 🛡️ SheShield

A Smart Women Safety Application developed using Flutter to protect women during emergency situations.

## ✨ Features

- 🚨 One-Tap SOS Alert
- 📍 Live GPS Location Sharing
- 🎥 Automatic Video Recording
- 🎤 Automatic Audio Recording
- 📞 Fake Call Feature
- 🔒 Evidence Locker
- 📜 SOS History
- 🏥 Nearby Police Stations
- 🏥 Nearby Hospitals
- 🗺️ Google Maps Integration
- 🌙 Dark Mode
- 📳 Triple Shake Detection (Automatically triggers SOS)
